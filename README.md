# 🚀 CS50W Project 3

This project is part of **CS50’s Web Programming with Python and JavaScript**.  
It focuses on building a dynamic web application with strong emphasis on **JavaScript**, **User Interface (UI)**, and **API Integration**.

---

## 📌 Overview

Project 3 challenged me to move beyond static pages and build a fully interactive web app.  
The goal was to create a smooth user experience while handling real-time data and dynamic updates.

---

## ⚙️ Key Features

### 🧠 JavaScript Functionality
- DOM manipulation for dynamic content updates
- Event handling for user interactions
- Asynchronous programming using `fetch` and Promises
- Partial page updates without full reloads

### 🔗 API Integration
- Fetching real-time data from APIs
- Handling JSON responses
- Error handling for failed requests
- Seamless data rendering on the frontend

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Django) 
- **APIs:** Internal APIs for dynamic data  

---

## 📚 What I Learned
